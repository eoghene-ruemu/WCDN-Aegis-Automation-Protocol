Overview

This lab implements an automated response pipeline that reacts to high-severity GuardDuty findings and triggers quarantine or containment actions through EventBridge, SNS notifications, and Lambda functions inside the Wakanda Cyber Defense Network.

What You’ll Practice

  • Integrating GuardDuty findings with EventBridge rules
  • Triggering Lambda functions for auto-remediation actions
  • Designing and documenting cloud incident response workflows
